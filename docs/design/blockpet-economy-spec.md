## 1. 規則

### 1.1 愛心乘數【定案】

| 愛心 | 乘數 |
|---|---|
| 1 顆 | ×0.6 |
| 2 顆 | ×0.8 |
| 3 顆 | ×1.0 |
| 4 顆 | ×1.2 |
| 5 顆 | ×1.4 |

- 愛心以 0.5 為單位；**半顆心無條件捨去**（2026-11-05）：1.5 顆＝×0.6、4.5 顆＝×1.2。
- 金幣永遠是整數（5 × 乘數都剛好是整數：3／4／5／6／7）。
- **同一張表用在兩個地方**（2026-11-05）：餵食金幣（1.3）和寵物移動速度（1.4）。整個專案只在一個地方定義這張表。
- 不到 1 顆心（0.5 顆）的情況見 3.1【未定】。

### 1.2 愛心回復【定案，2026-11-05】

| 情況 | 愛心 |
|---|---|
| 命中「現在想吃」 | +1 顆 |
| 沒命中 | +0.5 顆 |

- 最多 5 顆，超過不累加。
- 取代設計文件 5.3「每張 +0.5」與設計稿「命中 +1、沒命中不加」。

### 1.3 餵一張照片拿到的金幣【定案】

| 情況 | 金幣 |
|---|---|
| 沒命中「現在想吃」 | +1（不乘乘數） |
| 命中「現在想吃」 | +5 × 愛心乘數 |

- **結算順序（2026-11-05）：先回復愛心，再用回復之後的愛心算金幣。**
  - 例：4 顆心命中 → 愛心變 5 顆 → 金幣 5 × 1.4 ＝ +7。
- 每餵一張照片結算一次；沒有每日上限。
- 「現在想吃」每 2 小時換一次，以伺服器時間為準。

### 1.4 寵物移動速度【定案，2026-11-05】

- 移動速度倍率＝1.1 的愛心乘數（捨去規則相同）。
- 速度只看「目前的愛心」，和有沒有餵食無關。
- 取代 AIController 目前的 1×～2.2×（待決第 5 項）。
- 設計文件 5.1 的「略快／正常／變慢」改以此為準：5 顆 ×1.4、4 顆 ×1.2、3 顆 ×1.0、2 顆 ×0.8、1 顆 ×0.6。

### 1.5 ~~今日題目獎勵~~（2026-11-06 刪除）

今日題目已刪除（設計文件第 2 節第 4 項），沒有這個金幣來源。

### 1.6 帳戶【定案】

- 營地只有一個金幣帳戶；所有成員賺的金幣都進這個帳戶。
- 用真錢買的金幣包也進營地帳戶。
- 所有成員都可以花。
- 每筆收入與花費都要記錄是誰賺、誰花（架構文件 Wallet）。
- 只有金幣一種貨幣，沒有鑽石。

### 1.7 花費【定案＋補充】

- 家具、環境（擴建）、場景、寵物蛋、復活，都從營地帳戶扣。
- **復活（2026-11-06 定案）**：在復活視窗直接付營地金幣，沒有復活藥水。先扣款再讓寵物醒來；扣款時寵物已經被別的成員救醒 → 金幣退回。帳本記成「復活」。價格見 3.7【未定】。
- 【補充】金幣不足時：購買失敗、帳戶不扣款、餘額不會變成負數。
- 【補充】餘額剛好等於價格時可以買（買完剩 0）。

### 1.8 不影響金幣的東西【定案】

- 家具（只影響掉心速度，見 5.18）
- 天氣（純畫面）
- 進化方向（裝飾已於 2026-11-06 刪除）

## 2. 驗收條件（每一行就是一個測試）

### 乘數表
- 愛心 1／2／3／4／5 顆 → ×0.6／×0.8／×1.0／×1.2／×1.4
- 愛心 1.5 顆 → ×0.6；2.5 顆 → ×0.8；4.5 顆 → ×1.2
- 金幣計算和移動速度讀到的是同一張表（改一個數字，兩邊一起變）

### 愛心回復
- 愛心 3 顆、命中 → 4 顆
- 愛心 3 顆、沒命中 → 3.5 顆
- 愛心 4.5 顆、命中 → 5 顆（不會變 5.5）
- 愛心 5 顆、沒命中 → 5 顆

### 餵食金幣（先回復愛心，再算金幣）
- 愛心 5 顆、命中 → 愛心 5、金幣 +7
- 愛心 4 顆、命中 → 愛心 5、金幣 +7
- 愛心 3.5 顆、命中 → 愛心 4.5、金幣 +6
- 愛心 3 顆、命中 → 愛心 4、金幣 +6
- 愛心 2 顆、命中 → 愛心 3、金幣 +5
- 愛心 1 顆、命中 → 愛心 2、金幣 +4
- 愛心 0.5 顆、命中 → 愛心 1.5、金幣 +3
- 愛心 5 顆、沒命中 → 金幣 +1
- 愛心 1 顆、沒命中 → 愛心 1.5、金幣 +1
- 愛心 2 顆，連續餵 3 張都命中 → 愛心 3 → 4 → 5，金幣 +5 +6 +7 ＝ +18
- 成員 A 和 B 各餵一張命中、愛心 5 顆 → 營地帳戶共 +14，紀錄分別記在 A、B 名下

### 移動速度
- 愛心 5 顆 → 速度 ×1.4
- 愛心 3 顆 → 速度 ×1.0
- 愛心 2.5 顆 → 速度 ×0.8
- 愛心 1 顆 → 速度 ×0.6
- 不會出現大於 ×1.4 或小於 ×0.6 的速度

### 帳戶與花費
- 營地有 500、買 450 的家具 → 成功，剩 50
- 營地有 450、買 450 的家具 → 成功，剩 0
- 營地有 449、買 450 的家具 → 失敗，仍是 449
- 買金幣包 → 金幣進營地帳戶，任何成員都能用來買東西

### 復活（價格用暫用值 100）
- 營地有 150、寵物死亡、付復活 → 剩 50，寵物醒來
- 營地有 100、付復活 → 剩 0，寵物醒來
- 營地有 99、付復活 → 失敗，仍是 99，寵物還是死亡
- 成員 A、B 幾乎同時付復活 → 只扣一次 100，另一筆退回
- 帳本有一筆「復活 −100」，記在付款的成員名下

### 不該變的
- 營地有寵物最愛的家具 → 餵食金幣和沒有時一樣
- 下雨 → 餵食金幣和晴天一樣

## 3. 未定（Claude Code 遇到要先問）

### 3.1 不到 1 顆心（0.5 顆）的乘數
半顆心捨去後會變 0，但乘數表沒有 0 顆。
- 金幣不受影響：因為先回復愛心，命中後至少 1.5 顆。
- **速度會受影響**：0.5 顆心的寵物走多快？
- 暫用值：當作 1 顆（×0.6）

5.5 寫死亡時想吃膠囊變「點我復活」。
